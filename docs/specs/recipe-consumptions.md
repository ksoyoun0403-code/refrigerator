# 레시피 재료 차감 사양

- 작성일: 2026-08-24
- 상태: 구현 완료

## 사용자 흐름

AI 생성 결과, 저장 레시피 또는 공유 레시피 상세에서 `보유 재료 확인`을 누르면 레시피의 사용 재료와 추가 필요 재료를 현재 냉장고와 다시 비교합니다. 데이터는 변경하지 않으며 각 재료를 `충분함`, `수량 부족`, `직접 확인 필요`, `보관 재료 없음`으로 표시하고 전체 조리 가능 여부를 요약합니다.

공유 레시피와 나의 요리책 목록 카드에는 재료명 존재 여부만 비교한 `보유 재료 3/4` 요약을 표시합니다. 모든 이름이 있으면 `모든 재료 보유`, 하나도 없으면 회색 `보유 재료 0/4`로 표시합니다. 이 배지는 수량의 충분 여부를 의미하지 않으며 정확한 판단은 상세 `보유 재료 확인`에서 수행합니다. 냉장고 조회가 실패하면 잘못된 0개 표시 대신 배지를 숨깁니다.

재료 반영 흐름은 다음과 같습니다.

1. `이 레시피로 요리하기`를 누릅니다.
2. 냉장고의 같은 이름 재료와 레시피 사용량을 비교한 예상 반영 화면을 표시합니다.
3. 자동 계산 가능한 재료는 `사용량 → 남는 양` 결과만 간단히 표시하며, 사용자가 `수정`을 누른 경우에만 입력창을 엽니다.
4. 수량 부족 또는 자동 환산 불가 재료만 처음부터 수정 영역을 표시합니다.
5. 하단에 반영 예정, 모두 사용, 제외·확인 필요 재료 수를 요약합니다.
6. `요리 완료 및 재료 반영`을 누르면 마지막 확인 안내를 표시합니다.
7. 확인 시 냉장고 수량만 변경하고 레시피는 그대로 유지합니다.
8. 남은 수량이 0인 식재료는 연결된 스캔과 함께 냉장고에서 제거하고 완료 안내에 표시합니다.

## 자동 매칭과 환산

- 공백과 대소문자를 정규화한 재료명이 같은 경우만 자동 연결합니다.
- 같은 재료가 여러 개면 유통기한과 구매일이 빠른 항목을 우선합니다.
- 같은 단위와 `g↔kg`, `ml↔L`만 자동 환산합니다.
- `개↔g`, `팩↔개`, `약간`, `적당량`, `한 줌`처럼 확실하지 않은 표현은 자동 환산하지 않습니다.
- 자동 환산이 불가능해도 냉장고에 이름이 같은 재료가 있으면 해당 항목을 표시하고, 사용자가 `요리 후 남은 양`을 직접 입력하여 차감할 수 있습니다.
- 수동 수정에서는 저장 단위도 함께 선택할 수 있으며, 선택한 `남은 양 + 단위`를 냉장고의 최종 값으로 저장합니다(예: `1병 → 700ml`).
- 같은 이름의 냉장고 항목이 여러 개면 사용할 항목을 선택할 수 있습니다.
- 냉장고 수량보다 많은 사용량은 그대로 차감할 수 없으며 사용자가 현재 수량 이하로 수정해야 합니다.
- 레시피의 추가 필요 재료와 기본 양념은 자동 차감 대상에 포함하지 않습니다.

## API

- `POST /v1/recipe-consumptions/preview`
  - 검증된 레시피 본문을 받아 사용 재료별 예상 매칭과 차감량을 반환합니다.
  - 데이터를 변경하지 않습니다.
- `POST /v1/recipe-consumptions`
  - `recipeTitle`, `idempotencyKey`, `deductions[]`를 받습니다.
  - 모든 식재료가 로그인 사용자의 소유인지 확인합니다.
  - 전체 차감을 하나의 Serializable DB transaction으로 처리합니다.
  - 같은 사용자의 같은 `idempotencyKey` 요청은 저장된 최초 결과를 반환하여 중복 차감을 막습니다.

## 데이터 보존

`recipe_consumptions`에는 중복 요청 판별을 위한 사용자, 요청 키, 처리 결과와 처리 시각을 저장합니다. 레시피 게시물이나 저장 레시피는 수정하거나 삭제하지 않습니다.
