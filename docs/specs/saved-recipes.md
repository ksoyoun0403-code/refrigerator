# MyRecipe 북마크 사양

- 작성일: 2026-08-21
- 상태: 구현 완료

## 목적

AI로 생성한 레시피를 북마크하고 `MyRecipe` 화면에서 다시 확인할 수 있게 합니다.
현재 인증 기능이 없으므로 모든 저장 레시피는 단일 사용자 데이터로 취급합니다. 회원가입 기능을 추가할 때 `SavedRecipe`에 사용자 소유 관계를 연결합니다.

## API

- `GET /v1/saved-recipes`: 저장한 레시피를 최신순으로 조회
- `POST /v1/saved-recipes`: 생성된 레시피 한 건 저장
- `DELETE /v1/saved-recipes/:id`: 저장 레시피 삭제

동일한 레시피를 반복해서 저장하면 내용 지문을 기준으로 기존 북마크를 반환합니다.

## 저장 구조

- 레시피 전체 구조는 JSONB로 보관합니다.
- 제목과 재료명 목록은 별도 열에도 저장합니다.
- 재료명 목록은 향후 커뮤니티의 재료 검색 필터 구현에 사용합니다.
- API Key나 사용자 식별 정보는 저장하지 않습니다.
